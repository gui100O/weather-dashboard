# Weather Dashboard

Dashboard de previsão do tempo desenvolvido com HTML, CSS e JavaScript, utilizando a API Open-Meteo.

O projeto exibe as condições climáticas atuais de Cruzeiro - SP, incluindo temperatura atual, máxima, mínima, probabilidade de chuva e previsão por hora.

## Funcionalidades

- Exibição da temperatura atual
- Temperatura máxima e mínima do dia
- Probabilidade de chuva
- Condição climática atual
- Previsão das próximas 12 horas
- Data atualizada automaticamente
- Layout responsivo para diferentes tamanhos de tela

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Python
- API Open-Meteo

## Como funciona

A aplicação realiza uma requisição à API Open-Meteo utilizando JavaScript e `fetch()`.

Os dados retornados pela API são recebidos em formato JSON e utilizados para atualizar dinamicamente os elementos da página.

O projeto também possui uma versão em Python (`clima.py`) desenvolvida durante o processo de aprendizado sobre consumo de APIs.

## API

Este projeto utiliza a API Open-Meteo para obter os dados meteorológicos.

## Objetivo

Este projeto foi desenvolvido como parte do meu processo de aprendizado em desenvolvimento web e consumo de APIs.

O objetivo foi compreender na prática como uma aplicação pode realizar requisições a uma API, interpretar dados JSON e utilizá-los para atualizar uma interface web.
